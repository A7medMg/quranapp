# القرآن الكريم

تطبيق Flutter عربي للقرآن الكريم والعبادات اليومية. يجمع قراءة القرآن والاستماع إليه، الأحاديث، الأدعية والأذكار، التسبيح، مواقيت الصلاة ومتابعتها، التقويمين الهجري والميلادي، واتجاه القبلة.

## المزايا

### الرئيسية والتنقل

- لوحة رئيسية تعرض التاريخ الهجري، مواقيت الصلاة المختصرة، الصلاة القادمة، آخر موضع قراءة، ومتابعة الصلوات.
- اختصارات مباشرة للقرآن، القبلة، الدعاء، الأذكار، التسبيح، الأحاديث، الصلاة، التقويم الهجري، والمظهر.
- التنقل بزر الرجوع يعيد المستخدم من التبويبات إلى الرئيسية؛ ومن الرئيسية يظهر تأكيد الخروج.
- دعم أربعة ألوان للواجهة: الأخضر، الأزرق، البنفسجي، والذهبي. يُحفظ المظهر المختار محليًا.

### القرآن الكريم

- قائمة بالسور الـ114 مع نوع السورة وعدد آياتها، والانتقال إلى أول السورة عند اختيارها.
- نص القرآن موجود محليًا في `assets/files/1.txt` إلى `assets/files/114.txt`، لذلك لا يحتاج تحميل النص إلى اتصال بالإنترنت.
- تقسيم الآيات إلى صفحات مرنة تناسب مساحة الشاشة، مع التنقل الأفقي وعرض عربي بخط Amiri.
- حفظ آخر سورة وصفحة، وحفظ موضع مستقل لكل سورة لاستكمال القراءة لاحقًا.
- تحميل السورة والصفحات المجاورة عند الحاجة، وتحليل بيانات السورة خارج واجهة المستخدم للمساعدة على سلاسة التصفح.
- الاستماع إلى آيات الصفحة الحالية بصوت القارئ محمد صديق المنشاوي، مرتّلًا. ملفات الصوت تُحمّل عند التشغيل من الإنترنت.
- أدوات الصفحة تتيح تحديد جزء لنسخه أو قص جزء من الصفحة وحفظ الصورة أو مشاركتها.

### الأحاديث

- تصفح صحيح مسلم وصحيح البخاري، إضافة إلى مجموعة «مختارات سابقة» الموجودة في بيانات التطبيق.
- بحث في نص الحديث ومعلومات الكتاب، وفلتر للمفضلة.
- قائمة بأسماء أو مقتطفات دالة بدل الاكتفاء بترقيم الحديث، مع المرجع ورقم الحديث.
- فتح الحديث والتمرير إلى الأحاديث التالية من دون الرجوع للقائمة، ونسخ الحديث أو مشاركته.
- تُحمّل بيانات المجموعة المختارة عند فتحها، وتُحفظ المفضلة محليًا.
- تحتوي النسخة المضمّنة على 7,360 مدخلًا عربيًا لصحيح مسلم و7,580 لصحيح البخاري. النصوص معروضة كما وردت في المصدر، ولا يجري التطبيق تحقيقًا مستقلًا للأحاديث.

### الأدعية والأذكار

- قسمان داخل المكتبة: أدعية وأذكار، مع فئات بحسب الموقف، وبحث في النص والعنوان والفئة والمرجع.
- مكتبة الأدعية تعرض 1,010 نصوصًا مختلفة بعد توحيد اختلافات التشكيل والكتابة؛ وتحتوي قائمة الأدعية على 1,282 مدخلًا.
- قائمة الأذكار تحتوي 359 مدخلًا. بعض النصوص تظهر في القسمين لأنها دعاء وذكر معًا.
- نسخ النص وإظهار مرجعه عند توفره.
- المكتبة والبيانات مضمّنة محليًا وتعمل دون اتصال.

### التسبيح

- اختيار الذكر من مجموعة أذكار، وعدّاد مستقل لكل ذكر.
- حفظ الذكر المختار والعدد محليًا ليستمر بعد إغلاق التطبيق وفتحه.
- إمكانية تصفير عدّاد الذكر المختار بعد التأكيد.

### الصلاة ومواقيتها

- اختصار «الصلاة» يفتح صفحة «صلاتي» التي تعرض الصلاة القادمة والعدّ التنازلي، وجدول الصلوات الخمس، وموعد الضحى، ومتابعة اليوم، وإعدادات التنبيهات.
- تحديد الموقع لحساب المواقيت محليًا باستخدام طريقة الحساب المصرية، وبعد إذن المستخدم؛ يُستخدم المذهب الشافعي لحساب العصر.
- يُعرض وقت الضحى بعد الشروق بنحو 25 دقيقة كتقدير لبداية الوقت؛ والضحى نافلة وليست من الصلوات الخمس.
- متابعة الصلوات تحفظ حالة كل يوم؛ تظهر العلامة تلقائيًا بعد مرور 15 دقيقة على موعد الصلاة، ويمكن تعديلها يدويًا.
- إعدادات منفصلة لصوت الأذان، والتنبيه قبل الصلاة (10 دقائق افتراضيًا، مع خيارات 5 و10 و15 و30 دقيقة)، وتذكيرات الأذكار.
- تذكيرات الأذكار الافتراضية كل ساعتين من 8 صباحًا إلى 10 مساءً، مع خيارات 3 أو 4 ساعات، ونصوص متناوبة مثل الصلاة على النبي والتسبيح والاستغفار.
- الإشعارات مجدولة محليًا لتعمل عند إغلاق التطبيق. على Android تُجدول مواقيت الصلاة لعشرة أيام، وعلى iOS لخمسة أيام مراعاةً لحد الإشعارات المعلقة؛ يعيد التطبيق جدولة المواعيد عند فتحه أو العودة إليه.
- للأذان ملف صوت Android مضمّن في `android/app/src/main/res/raw/adhan.ogg`. أما تنبيهات الصلاة والأذكار فتستخدم صوت الإشعار الافتراضي للجهاز، بحسب إعدادات النظام.

### اتجاه القبلة

- تحديد الموقع وقراءة اتجاه البوصلة لعرض اتجاه القبلة.
- إظهار حالة واضحة عند رفض إذن الموقع أو عدم توفر حساس البوصلة، مع رابط لإعدادات الجهاز عند الحاجة.

### التقويم

- تقويم تفاعلي يعرض التاريخين الهجري والميلادي.
- التبديل بين عرض التقويمين والتنقل بين الشهور والعودة إلى تاريخ اليوم.
- اختصار الرئيسية يفتح التقويم على العرض الهجري.

## البدء والتشغيل

### المتطلبات

- Flutter SDK وDart SDK بما يوافق قيد Dart في `pubspec.yaml` (`^3.10.1`).
- إعداد Android Studio أو Xcode لتشغيل التطبيق على الجهاز أو المحاكي المناسب.

### التشغيل

```bash
flutter pub get
flutter run
```

لتشغيل الاختبارات:

```bash
flutter test
```

تشغيل الصوت يحتاج اتصالًا بالإنترنت. نص القرآن والأدعية والأذكار والأحاديث الأساسية مضمنة محليًا.

## الأذونات والإشعارات

- **الموقع:** مطلوب لحساب مواقيت الصلاة واتجاه القبلة. يطلب التطبيق الإذن عند استخدام الميزة.
- **الإشعارات:** مطلوبة للأذان والتنبيهات والتذكيرات. يجب السماح بها من النظام، ويمكن تعديل صوت القنوات من إعدادات الجهاز.
- **التنبيه الدقيق على Android:** قد يطلب النظام إذن المنبهات الدقيقة؛ إذا لم يُمنح، يستخدم التطبيق جدولة غير دقيقة وقد يتأخر وصول الإشعار.
- **الصور والمشاركة:** تُطلب صلاحية الصور عند الحاجة لحفظ صورة الصفحة، وفق النظام وإصدار الجهاز.

إيقاف إشعارات التطبيق أو كتم صوتها من النظام يمنع وصول الصوت حتى لو كانت خيارات التطبيق مفعّلة. كما أن إغلاق التطبيق إجباريًا من إعدادات النظام قد يقيّد الإشعارات على بعض الأجهزة.

## تنظيم المشروع

الكود منظّم حسب الميزة تحت `lib/features/`:

| المسار | المسؤولية |
| --- | --- |
| `lib/app/` | إعداد التطبيق وموفّرات الحالة والمسارات. |
| `lib/core/` | الثوابت والثيمات والمكوّنات المشتركة. |
| `lib/features/home/` | الرئيسية والاختصارات والتنقل. |
| `lib/features/quran/` | قارئ القرآن، الصوت، حفظ موضع القراءة، وقصّ/مشاركة صور الصفحات. |
| `lib/features/hadith/` | مكتبة الأحاديث، التفاصيل، والـمفضلة. |
| `lib/features/dua/` | مكتبة الأدعية والأذكار. |
| `lib/features/sebha/` | التسبيح وحفظ العدّادات. |
| `lib/features/prayer/` | حساب المواقيت، التتبع، الضحى، والإشعارات. |
| `lib/features/calendar/` | التقويم الهجري والميلادي. |
| `lib/features/qibla/` | تحديد اتجاه القبلة. |
| `lib/features/settings/` | اختيار ثيم التطبيق. |

تُدار الحالات المشتركة عبر `Provider` و`ChangeNotifier`، ومنها حالة الثيم والقراءة والمفضلة والتسبيح ومواقيت الصلاة. تُحفظ التفضيلات والبيانات الشخصية البسيطة عبر `shared_preferences`.

أهم الحزم المستخدمة: `adhan` لحساب المواقيت، `geolocator` للموقع، `flutter_local_notifications` و`timezone` لجدولة الإشعارات، `just_audio` للصوت، `share_plus` و`gal` للمشاركة وحفظ الصور، و`hijri_date` و`flutter_device_compass` للتقويم والبوصلة.

- تفاصيل مصادر الأحاديث والأعداد والتراخيص: [HADITH_DATA_SOURCE.md](HADITH_DATA_SOURCE.md).

- خدمة تلاوة المنشاوي تستخدم روابط صوتية من Quran Cloud CDN، لذا تحتاج اتصال إنترنت أثناء الاستماع.
